# 异界 · Another World

> 双人对战 · 局内动态构筑 · 12 格线性战场的策略卡牌游戏

《异界》是一款回合制卡牌对战游戏。开局没有卡组——你和对手共享同一副公共大牌库，
每回合花能量抽牌，边打边把牌组搭出来。一个阶段三个回合：你行动、对手行动，
然后战斗回合把双方摆好的局面一次性同时结算。站满格子、卡准对位、算清阶位，
才能让空打的伤害砸在对手脸上。

## 核心特色

- **局内构筑，无需赛前组卡**：从公共大牌库随机抽牌。主动抽牌 1 点能量一张（每回合上限 5 次），
  卡牌效果抽牌不受此限。神选者独立成堆，开局每人 1 张，全局最多再抽 5 张。
- **三回合一阶段**：我方回合 → 敌方回合 → 战斗回合。先手每阶段轮换，
  后手在单轮内握有「最后行动者优势」，也是为下一轮先手进攻铺路的心理筹码。
- **12 格线性战场，对位钉死**：每方 6 格（前 / 后排各 3 格），对位由编号绝对决定
  （`0↔6` … `5↔11`），「人在哪，就打哪」。换位会立即改写对位。
  对位空着即「空打」，按当前**阶位**直接打脸——`0/1/3/5` 费对应 `0–3` 阶。
- **战力一次算清**：战斗回合全自动，顺序为战斗回合开始 → 先手 → 全体同时攻击 →
  退场与反击 → 存活人数对比 → 玩家最终伤害判定。攻击与死亡视为同时发生，可以同归于尽；
  双方本回合受到的伤害相减，**只有数值高的一方承受差值**。
- **前缀不只是标签**：渊、机械、灵能、神灵画卷、血歌（群峦、潮汐筹备中）。
  灵能单位自带「附着」，可挂在友军身上提供增益且自己不吃伤害、不计存活；
  血歌单位能**用生命值代替能量全额付费**，且在敌方单位退场时可将前缀传染给己方单位。
- **特性链有唯一解**：进场 / 先手 / 退场 / 主动退场 / 反击 / 抛置。同一时点的效果按「树」分级结算——
  0 级全部处理完才进 1 级，连锁期间阶段推进暂停。规则绝对自洽，不留裁定空间。
- **反制牌的心理战**：反制法术先置入反制区、**不立即付费**，对手知道它存在，
  却看不到它的效果与支付方式；条件满足自动触发，期限到了没触发照样扣费（能量可为负，生命可扣至死）。
- **资源可互换**：生命、能量、手牌、战场单位之间存在高风险高回报的转化路径。

## 一局怎么走

1. 开局：20 点生命、起始 3 张手牌（2 张普通牌 + 1 张神选者）。
2. 己方回合：获得 6 点能量（上限 15，**可留存、可为负、不重置**），召唤、施法、花能量抽牌。
3. 敌方回合：对手同样操作。
4. 战斗回合：全自动结算，对位互殴、空打按阶位、比存活人数，最后取双方伤害差值。
5. 阶段结束，先手交换，进入下一阶段。先掉到 0 血的一方出局（生命值可被扣至负数）。

## 技术

- **引擎**：Unity 2022.3.62f1 LTS，内置渲染管线 + TextMeshPro + UGUI。
- **联网**：Mirror，Steam 传输层（FizzySteamworks）。大厅支持快速匹配、创建房间、加入房间，
  并记录总场数 / 胜率 / 连胜。
- **单机**：离线 AI 对手，采用身材 / 光环 / 先手 / 神选者多维评分制决策，难度分档，
  走 Host 本地流程，与联机共用同一套规则代码。
- **构建**：CI 在推送 `v*` tag 时自动构建 Windows 播放器并发布 Release。
