# common-bg-v1 —— 通用背景底板

**用途**：多个场景共用的深色底图（卡牌总览 / 商店 / 设置 / 战绩…）。**不是大厅背景** —— 大厅用 Generated/lobby-v1/LobbyBack.png + 徽记，两者不混用（用户 2026-09-26 明确）。

**用户 2026-09-26 原话**：「先出一张通用型背景，不需要很多装饰（可以有一些暗纹装饰），会用在很多地方，应支持单项缩放而不奇怪，将会用于一些不同场景的背景」。

## 为什么只用三类元素（非等比缩放的硬约束）

整张图只有：① 纵向渐变 / 大范围柔光；② 轴线直线（竖 / 斜，极淡）；③ 微尘（无定形亮点）。

**明确排除圆、六芒星、菱形、任何有辨识轮廓的徽记** —— 这些一拉就废（圆变成压扁的椭圆环，一眼假）。①拉伸只变椭仍读作「一片光」，②只是间距变化，③仍是噪点。**改这张图时不要往里加任何有轮廓的纹样。**

## 踩过的坑（改脚本前必读）

1. **`BoardLayersV2.ps1` 的 `Fill-Radial` 不能用在这个尺寸。** 它走 GDI+ `PathGradientBrush.SetSigmaBellShape(focus)`，实测**不是「中心亮、边缘淡」，而是在笔刷中心留一个透明洞**（σ=0.92 实测：r=0 为 0，r≈0.15·rx 才到峰值）。战场用它时半径只有 150–620px，洞小、被纹理盖住看不出来；一放大到 rx=1620 就摊成画面中央一块 700×360 的暗斑（用户 2026-09-26 判「不要这种暗斑点」）。
   **修法**：本脚本自带 C# 辅助类 `AwSoftGrad::Pool`，显式做「中心 α 峰值 → 椭圆边界 α 0」的线性衰减。`BoardLayersV2.ps1` **没有改**（战场在用），这里是本地覆盖的 `New-SoftPool`。
   ⚠️ .NET (Core) 的 `Blend` **没有 `Colors` 属性**（只有 `Positions` / `Factors`），且没有双参构造函数 —— 只能用 `New-Object Blend($n)` 再赋值。想显式控曲线时注意这点。
2. **不要加暗色噪点 / 分块 / 网格。** 首版的 `Add-Pits` 暗斑 + 石缝分块 + 512px 粗网格被用户判「不符合风格」（2026-09-26）。现在的 ② 只有极淡的轴线细线。
3. **实测平滑度**（A 方案，200px 行内极差）：y=300 时 8、y=700 时 6，相邻像素最大跳变 1–2 —— 梯度本身，没有抖动噪声。

## 接线注意

`Assets/_Game/Art/Sprites/Generated/` 下的 PNG 是 Unity 默认导入（`textureType: 0`，**不是 Sprite**），而 `Resources/Backgrounds/` 下是 `textureType: 8`。要在 UI 里当 Image 用，导入设置得改成 Sprite 或改用 RawImage；覆盖贴图时**别连 `.meta` 一起换**。全屏容器保持**拉伸锚**（非等比拉伸是本图的设计前提）。
