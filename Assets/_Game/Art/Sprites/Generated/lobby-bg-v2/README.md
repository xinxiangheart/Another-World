- 屏幕 1920×1080 → 贴图 2074×1166；**把容器缩放到 1.08 即可**（或按贴图 1:1 建 2074×1166 的容器）。

- 星环是**独立层**，贴图自带 46 屏 px 留白，场景里按「贴图像素 ÷ 出图倍率」定尺寸、中心对到屏坐标即可：

## 星环：与战场环的差异

战场环实测（`board-layers-v2/Board_Sigil.png` + `Board_Rune.png`，贴图半径 px）：
L3 主环带 **412–418** + **24 根等长**刻度 + **4 颗**菱形铆钉 464–471 + **8 个**外侧空心三角 477–521 + 环内一圈钢色亮线；
L4 蓝环 292–336 + 六芒星 50–252 + 中央金菱形 0–31 + 蓝芯 24。
一句话：**单条环带 + 等长刻度 + 环外三角 + 中央星形**。

大厅环逐条对开（同源不同形：不换色、不换线法）：

| # | 战场 | 大厅 |
|---|---|---|
| ① 环 | 单条环带（两条细线夹一条带） | **两条独立细金环** R350 / R318 |
| ② 刻度 | 24 根**等长** | **36 个槽位**分三档：长 4（跨过双环，落正上下左右）/ 中 8（夹在双环之间）/ 短 12（只挂在外环内侧），另 12 个**空槽** |

| ④ 环外 | —（光晕在环内、更亮） | R388 一圈**极淡钢色轨道环**（α26） |
| ⑤ 中央 | 六芒星 + 金菱形 + 蓝芯 | **留空**，星野直接透出来 |

## 环上的 12 颗点：怎么「独立亮起部分点」

- 槽位角 = `$RING_A0 + i × 10°`（`$RING_A0 = -90` 即正上方），**只有 `i % 3 == 1` 的槽位是点**
  → 点角 **-80° / -50° / -20° / 10° / 40° / 70° / 100° / 130° / 160° / 190° / 220° / 250°**（顺时针，每 30° 一颗）。
  坐标函数 `Get-RingNodePoints($cx, $cy, $r)`（在脚本里），半径取 `$RING_R = 350`。
- 贴图与辉光**出成近白**，运行时**每颗一个实例、只改 `color`**：

  | 态 | tint（RawImage.color） | 叠加 |
  |---|---|---|
  | 暗 | `(0.40, 0.33, 0.16)` α 0.85 | 无 |
  | 亮 | `(0.91, 0.82, 0.54)` α 1.00 | 一张 `Ring_NodeGlow`，tint `(0.91,0.82,0.54)` α 0.62 |

- 想亮几颗亮几颗、想亮哪颗亮哪颗，**不重出图**。

## 场景接线（2026-09-26）

生成脚本 `Assets/_Game/Editor/LobbyBgV2Builder.cs`，菜单 `Tools → 异界 → 生成大厅背景 v2（占位）` / `删除大厅背景 v2`。
运行时组件：`Assets/_Game/Scripts/UI/Lobby/LobbyBgParallax.cs`（视差）+ `LobbyRingNodes.cs`（点亮点）。

节点树（挂在已有的 `LobbyUI_v1` 下，**sibling index 1** —— 压在 `Ref_Backdrop`（安全网）之上、其它一切之下）：

| 节点 | 组件 | 摆位 | 视差 depth |
|---|---|---|---|
| `Bg_v2` | `LobbyBgParallax` | 全屏空容器（不画东西） | — |
| `Bg_v2/Far` | RawImage `Bg_Far` | 全拉伸 + `localScale 1.08` | 0.25 |
| `Bg_v2/Ring` | `LobbyRingNodes` | 中心锚 `792×792`，中心 = 屏 **(560, 540)** | 0.55 |
| `Bg_v2/Ring/Base` | RawImage `Ring_Base` | `792×792` | — |
| `Bg_v2/Ring/Glow_00..Glow_11` | RawImage `Ring_NodeGlow` | `112×112`，半径 350，屏角 `-80 + 30i` | — |
| `Bg_v2/Ring/Node_00..Node_11` | RawImage `Ring_Node` | `52×52`，同上 | — |
| `Bg_v2/Near` | RawImage `Bg_Near` | 全拉伸 + `localScale 1.08` | 1.00 |

- 12 张辉光**整批建在 12 颗点之前**，所以辉光永远渲染在点之下。
- 环上 12 颗点有两种态：
  - **常亮** `litCount`：前 N 颗钉死在满亮，默认 **0**（要「独立亮起部分点」就调它）；
  - **自身闪烁** `twinkleOn`：**每一颗自己**缓慢亮暗 —— 不是灯头在跑，是 12 颗各闪各的，靠相位差连成一道缓慢的**顺时针**微光波。
    `twinklePeriod` 一颗自己亮一次几秒（默认 **6**，越大越慢）、`twinklePhaseStep` 相邻两颗错开多少周期（默认 **1/12** = 一圈正好一个周期）、
    `twinkleMin` → `twinkleMax` 亮暗两档（默认 **0.06 → 1.00**：最暗接近熄灭、最亮满亮）。
    亮度走**正弦**，所以是连续变化，**不会亮一下停一会儿**；`twinkleOn = false` 就完全静止。
- 闪动要**进 Play** 才看得到；不想进 Play 就勾上 `previewInEditMode`（编辑态也会一直闪，代价是场景一直被标成「已修改」）。编辑态静止时相位停在 0 —— 环上是一条亮度渐变的带。
- 远景 / 近景用「全拉伸 + `localScale 1.08`」而不是固定 2074×1166 —— 16:9 下正好 1 贴图像素 = 1 屏像素，换比例也自动铺满。
- 视差**只在 Play 生效**；场景里静止的摆位就是设计稿位置（`Tools/cardframe/LobbyBgV2.ps1` 的屏坐标）。
- 坐标换算：脚本 / 本文件的屏口径是「左上原点、y 向下」，`anchoredPosition` 是「中心原点、y 向上」—— x 取 `(屏x - 960)`、y 取 `-(屏y - 540)`；角度同理取负。
- `Ref_Emblem`（中央棋盘徽记）被生成器**关掉**（`SetActive(false)`，没删）：它是「中央大圆环 + 六芒星」那套母题，与左侧新星环同框就是两套圆环叠加。菜单 `Tools → 异界 → 大厅：切换旧徽记 Ref_Emblem` 一键切回。
