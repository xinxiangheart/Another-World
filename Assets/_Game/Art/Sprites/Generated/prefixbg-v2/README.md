# 前缀底图 v2（画窗底图）

> **已于 2026-09-24 安装**：7 张**原地覆盖**到 `Assets/_Game/Resources/Cards/PrefixArtBG/`。
> 只覆盖 `.png`，`.meta` 一律未动 —— **guid 不变 → 预制体 / 场景零改动**。
> 覆盖前的 v1 图备份在 `%TEMP%\prefixbg-v1-backup-20260924\`；v1 之前的旧图在 `%TEMP%\prefixbg-backup-20260924\`。
> 本目录保留为归档 / 对照稿。**v1（`Generated/prefixbg-v1/`）已被本版取代，只作对照。**

v1 的两个问题（用户实机反馈）：

1. **太暗**——底纹几乎看不出颜色。
2. **区分点全在中央**——中央被召唤物立绘挡掉，所以认不出前缀。
   前缀底图的用处就是「在战场上也能一眼看出前缀」。

v2 的对策：

- **身份搬到画窗边带 + 四角 + 上下缘**。实测 14 张 1 费卡的原画 alpha bbox：左右各留 **5~17%**、
  上下 **3~15%** 的空边，**四角基本全露** —— 这三处才是唯一「永远看得见」的地方。
- **每个前缀一套自己的底**（色相 + 明度走向都不同），不再共用一个暗底。
- 中央母题降到 `0.40` 透明度的纯纹理；中央另压一道 20% 的暗，让原画更跳。

## 每个前缀自己的底

`PrefixBgV2.py` 顶部 `FIELDS`：`(顶色, 底色, 明度走向 mode, 强度 amt)`

| 前缀 | 顶 → 底 | mode | 读感 |
|---|---|---|---|
| 灵能 Psychic | `(26,64,84)` → `(9,24,38)` | `vignette` | 冷青，中间渗冷光 |
| 渊 Abyss | `(56,28,82)` → `(15,9,30)` | `invert` | 紫，中心最黑、向外发亮（洞口） |
| 机械 Mech | `(68,52,34)` → `(22,17,13)` | `corner` | 暖褐钢，左上受光 |
| 血歌 Blood | `(72,26,36)` → `(24,8,15)` | `bottom` | 酒红，血往下积 |
| 神灵画卷 Scroll | `(26,62,50)` → `(8,26,22)` | `midband` | 墨绿，卷面横带受光 |
| 通用 Common | `(38,42,50)` → `(18,20,26)` | `flat` | **中性炭灰**，最素、无属性 |
| 法术通用 Spell | `(32,48,74)` → `(12,18,34)` | `top` | 钢蓝，上亮下暗 |

mode 可选：`vignette`（边暗中间亮）/ `invert`（中心最黑）/ `top` / `bottom` / `corner`（左上受光）/
`midband`（中间一条横带亮）/ `flat`（几乎不平）。

> **通用刻意做成「炭灰」而不是蓝**：原来通用与法术都是蓝底，摆一起分不出来；通用是「无前缀」，
> 本该是最没有性格的那张。现在通用 = 灰 + 金细边，法术 = 蓝 + 钢蓝边。

## 边带 + 四角 + 上下缘（身份层）

> **2026-09-24 修（用户反馈）**：法术那张原来是 40px 厚边带 + 内侧第二道框 + 上下符文刻度 + 四角十字刻线，实机看着「太厚、太装饰」。现在只留 **24px 细边带 + 四个小方角点**，内框与刻度全删。

共用：一条内缩 14px、厚 46px 的**内框色带**（近满色 α214）。四角标记尺度见各条。

| 前缀 | 内框色带 | 四角 | 上下缘 |
|---|---|---|---|
| 灵能 | 满色 + 内侧第二道细框 | 六棱晶块（外填内空） | 四边等距刻度脊（向内 30px） |
| 渊 | 满色 | **眼形**（上下睑弧 + 虹膜 + 竖瞳） | 沿带内侧一列吸盘弧，四边都有 |
| 机械 | 满色 | 斜切方角 + 铆钉 | 四边等距**齿条**（方块齿） |
| 血歌 | 满色 | **音符** | 上缘三层声波弧 + 下缘三颗滴落 |
| 神灵画卷 | 较细（34px） | **卷轴端头**（胶囊） | 上下**实心卷杆**贯穿整宽 |
| 通用 | 最细（30px）+ 降透明 | 菱形钉 | 双细线（无花纹） |
| 法术通用 | **最细（24px），无内框** | **小方角点**（无刻线） | **无** |

明度常量（`PrefixBgMotifsV2.py` 顶部）：`BAND, BAND2, CORNERA, PAT = 214, 118, 198, 168`。

## 本轮修的两处错位（法术）

以前法术底图是 64x84 挂在 `ArtworkArea` 里的 `(0,-10)`，而法术画窗是 **64x64 @ (0,12)**
（`PrefixArtBG` 是 `ArtworkArea` 的子节点，坐标相对父节点）—— 结果底图**顶端对不齐、底部多出 20 单位**（被名牌盖住）。
方形底图配上那个节点还会被纵向拉伸 31%。

| 文件 | 字段 | 旧 | 新 |
|---|---|---|---|
| `Assets/_Game/Prefabs/Cards/Spell/SpellCard00_New_2D.prefab` | `PrefixArtBG` `m_SizeDelta` | `64, 84` | **`64, 64`** |
| 同上 | `PrefixArtBG` `m_AnchoredPosition` | `0, -10` | **`0, 0`** |
| `Assets/_Game/Prefabs/Cards/Spell/SpellCard00_New_3D.prefab` | `PrefixBg` `m_LocalPosition` | `0, 0, 0.09` | **`0, 0.133, 0.09`** |

3D 那条的 0.133 是算出来的：法术画窗开口在 768x1344 画布上是 `y 267~857`，中心 y=562，
画布中心 672 → 高出 110px；frame 每 px = 0.00119 世界单位 → **+0.131**。该预制体自己的
`CardArt` 就在 `y 0.133`，改完两者对齐。

## 生成脚本

| 文件 | 作用 |
|---|---|
| `Tools/cardframe/PrefixBgV2.py` | 主脚本。仓库根目录 `python Tools/cardframe/PrefixBgV2.py` 整套重出 + 装到 `Resources/` |
| `Tools/cardframe/PrefixBgMotifsV2.py` | 边带 / 四角 / 上下缘的几何（**改形状改这里**） |
| `Tools/cardframe/PrefixBgV2Preview.py` | 出上面两张预览（读真实 v7 卡框层 + 真实卡图合成） |

可调项：`FIELDS`（底色 / 明度走向 / 强度）、`TINT`（花纹色相）、`CENTER_ALPHA`（中央母题透明度，默认 0.40）、
`PrefixBgMotifsV2` 顶部的 `INS / BT / BAND / BAND2 / CORNERA / PAT`。

> `PrefixBgV2.py` 直接往 `Resources/` 写，重跑即重装；跑之前想留底先备份。

## 已知边界
