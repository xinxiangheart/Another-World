# 卡面制作指南（新卡面 · 操作手册）

> **这份文件管「怎么做」：路径、命名、规格、出图、抠图、落盘、验收。**
> 它**不管「画成什么样」** —— 画风与内容规则一律在 `AGENTS.md`。引 AGENTS.md 时**按标题搜，不要按行号**：那份文件一直在增补，行号会漂。
>
> AGENTS.md 里与本文件直接相关的节（按标题搜）：
> - `界面 / 场景美术方向` —— 只管 UI / 场景层，**不管立绘**
> - `卡牌立绘风格基准` / `基准换代` / `辨识度硬指标` / `1–3 费的脸` / `半背景（衬托）画法`
> - `费用档位与画面体量` / `5 费（传奇）档` / `前缀配色` / 气质层
> - `卡面内容准则`（卡面里不许出现「卡牌游戏」）
> - `生成配方` / `抠图注意事项` / `落盘规范`

## 1. 一张新卡面必须落在哪（路径由代码决定，写错就静默不生效）

加载代码：`Assets/_Game/Scripts/UI/Board/CardDisplay2DNew.cs` 的 `GetCardArtSprite()`（同文件 640 行起的注释就是权威说明）。

解析顺序：

1. 模板的 `cardSprite2D` 字段 —— **已废弃**，一律走下面的路径加载。
2. **路径加载**（镜像 `Resources/CardData` 的目录结构），相对 `Resources/` 的根是 `Cards/`：
   - 召唤物：`Cards/Summon/{SummonType}/{cost}/SummonCard_{templateID}`
     - `Hero` → `Hero/{baseCost}` —— **按 baseCost 分目录，不是 baseTier**（3 费卡 `baseTier=2`，但图在 `Hero/3`）
     - `ChosenOne` → `ChosenOne/`
     - `Special` → `Special/`；找不到会**兜底**再试 `Hero/{baseCost}`（两处都有图时以 `Special/` 为准）
   - 法术：`Cards/Spell/Normal/{cost}/SpellCard_{templateID}` 与 `Cards/Spell/Special/{cost}/SpellCard_{templateID}` —— **两个子目录都试**
3. 全都失败 → 返回 `null` → **隐藏 CardArt 层，露出下层的 `PrefixArtBG` 前缀底图**（这是兜底，不是报错）。

**命名两种都认**：`SummonCard_{01103}.png`（现行，带花括号）与 `SummonCard_01103.png`（不带）。
**落盘根目录**：`Assets/_Game/Resources/Cards/...`

## 2. 规格

- 画布 **1152 x 1536**（3:4）。全库现行规格。
- **四角 + 内缩 46px 边带必须保持透明** —— 这是功能要求（保证战场上能认出前缀），不是审美偏好。依据见 AGENTS.md「半背景（衬托）画法」。
- 衬托物只允许出现在**画窗中央**：召唤 `x76–692 / y268–1043`，法术 `y268–856`。
- **外部参考件两份，出图前先打开**（路径与分工见 AGENTS.md「参考件索引」）：`图片参考.docx` 管**背景 / 视角 / 细节**，`脸部参考.docx` 管**脸**。
- **`图片参考.docx` 给的是四条轴：姿势 / 身体 / 视角 / 背景** —— 站定为主调、环绕式小背景（四角留空）。**不取精细度，取景与视角自 2026-09-26 起也不取**（那批是 32/32 全身构图，照抄会把脸压到个位数像素）。**取景改「半身偏七分」**，见 AGENTS.md「商业化卡面基准（召唤物）」；逐轴规则见「半背景（衬托）画法」。
- 透明底一律走**洋红键抠图**（出图时加 `--transparent`）。
- 旧规格残留只有 `01130`（1800x2400，且无卡数据），别照它当标准。

## 3. 出图

- **模型、工具链、提示词前缀**：见 AGENTS.md「生成配方（已实测可用）」与各前缀细化节。提示词前缀**照抄，一字不改**。
- **拼法（2026-09-26 起）**：前缀 → 前缀修饰 → 气质 → 角色描述 → **脸模片段** → 衬托物 → **结尾复述脸** → `transparent background, 3:4 portrait, no text, no border`。**脸模要提前 + 结尾再点名一次**（模型对长提示词的中间最不敏感，旧拼法把它埋在正中间）。
- **负向提示词无效**：`ofoxai` 会**静默忽略** `--negative`（返回里写着 `negative prompts ignored`）。所有约束必须写进**正向正文**，别指望负面词。
- **体检（两道脚本，都要跑）**：① `python Tools/cardface/gate_check.py --tier <1|3|5> <png...>` —— 直接量生成器直出的洋红底候选（没 alpha 时按四角键色推定背景），出「明度跨度 / p90 / 高饱和占比 / 46px 边带 / 洋红残边」，`--pairwise` 再跑第 4 道门；② `python Tools/cardface/design_check.py <抠好的图>` —— **四条设计轴**（明度阶梯 / 色相簇 / 细节密度 / 高饱和 / 最亮块 / 近黑，6 项最多 1 项不达标）。**2026-09-26 起这两道是硬门**，见 AGENTS.md「四条设计轴」。
- **候选数量**：5 费每张 3 个候选（必须明显不同）；1 / 3 费 2 个候选封顶。
- **内容层**：出图前先把提示词里内容层的卡牌游戏词（`card / deck / hand / draw / mana / cost / slot / token`）换成世界观说法 —— 见 AGENTS.md「卡面内容准则」。出图后再自问一次「这张图像卡牌游戏吗」。
- **气质**：按角色加，基底里的 `dark fantasy` 不动 —— 见 AGENTS.md「气质层」。
- **衬托物画什么由角色反推，不由文档派**：顺序永远是「先读这个角色是谁 → 再决定身后立什么」。判据：把衬托物换到另一张卡上还成立，就说明它没在衬托这个角色。
- **四轴先定，再写提示词**：① 姿势（站定 / 坐 / 动态，站定要有重心与持法）；② 身体（**人形：半身偏七分，头到腰 ~ 头到膝，3–5 头身，头在画窗里 ≥1/5 高；`全身` 只给非人形**）；③ 视角（**不再默认俯视**：平视或**轻度**俯视，`slightly high camera angle`，**不许从头顶俯下去**；朝向可 3/4、侧、背）；④ 背景（半背景、四角留空、可环绕主体两侧）。**姿势 / 视角 / 背景**照 32 张参考图，**取景与精细度都不照**（取景看 AGENTS.md「商业化卡面基准（召唤物）」，精细度走「辨识度硬指标」）。**5 费也不判「有没有在动」，只判「有没有张力」** —— 站定按 AGENTS.md「可用姿势 · 站定向」那六个装置审。
- **四条设计轴（2026-09-26 新增，用户判「完全不合格」的那四轴）**：**服装 / 特效 / 角色细节 / 脸与头发** —— 写法与门槛见 AGENTS.md「四条设计轴」。要点：服装 ≥3 层 + ≥2 构件 + **≥2 种材质**；**每张必须有一处明确特效**（高饱和与近白的主要来源）；头发 ≥3 组可辨发束 + 一条高光带、发型要进剪影。**旧的「低饱和 / 禁渐变 / 低细节密度」三条已作废**，别再把它们写进提示词。

## 5. 落盘

1. 新图**先出到** `Assets/_Game/Art/Sprites/Generated/` 下（不要直接覆盖正式资源）。
2. 确认后再替换 `Assets/_Game/Resources/Cards/...`，**保留原 `.meta`** —— GUID 变了预制体引用会断。
3. 被换下来的旧图移到 `Assets/_Game/Art/Old/Summon/...`，并在 `Assets/_Game/Art/Old/README.md` 的「替换记录」表登记（形象、取舍、抠图参数）。
4. 同步更新 `Docs/卡面台账.md` 的缺口表。

## 6. 验收清单

- [ ] 尺寸 1152 x 1536
- [ ] 四角与内缩 46px 边带是透明的
- [ ] 缩到卡面尺寸时**剪影仍读得出来**、不糊。**实测尺寸**：画窗 `ArtworkArea = 64 × 84`（`Card00_New_2D.prefab`），1152 → 64 缩放 **0.0556** —— 卡面上脸约 **9.7px**、虹膜约 **1.2px**。**所以卡面尺寸下读不出五官是必然的，这一条只判剪影，不判脸**（脸的验收看下面那两条，按放大图的立绘尺度判）。
- [ ] 衬托物换到另一张卡上也成立 → **不合格**（衬托物必须是这个角色的特点）
- [ ] 四轴对过：姿势（站定为主）、身体（**人形是半身偏七分、3–5 头身；放大数不出 ≥6 头身**；非人形才可全身）、视角（平视或轻度俯视、朝向按角色）、背景（半背景、四角留空）
- [ ] 缩到卡面尺寸（约 90×118）仍认得出：脸/头没有糊成一个点，剪影与主体色块仍可辨认（`thumbSD ≥ 40`）
- [ ] 5 费姿势判的是**张力**不是动：遮掉背景只留剪影，这张图仍然「有戏」（站定用六个装置审）
- [ ] ~~精细度没有跟着参考图走：衬托物仍是硬边平涂、低细节密度~~ **2026-09-26 改**：**衬托物**仍是硬边平涂（这条不变）；但**主体**的细节密度现在是**下限（≥10）**，「更精致 / 更亮」不再算跑偏 —— 跑偏的真信号只有「底色被软过渡糊掉」和「写实解剖」
- [ ] 跑过 `design_check.py`：**明度阶梯 ≥6 / 色相簇 ≥4 / 细节密度 ≥10 / 高饱和 4–30% / 近白 ≥3% / 近黑 ≤45%**，6 项最多 1 项不达标
- [ ] 四条设计轴逐条对过：**服装**（≥3 层 + ≥2 构件 + ≥2 种材质，相邻两层差 ≥2 级）、**特效**（有一处明确特效，且它是高饱和 + 近白的主要来源，但不碰四角与 46px 边带）、**角色细节**（≥1 个能进剪影的独有识别物 + 细碎结构密度够）、**头发**（≥3 组可辨发束 + 一条高光带 + 发型进剪影 + 发色与肤色差 ≥3 级）
- [ ] 过一遍 AGENTS.md「辨识度硬指标」（不许再出「灰人」；骨相 / 眼型 / 年龄 / 性别 / 标记逐张差异化）—— 注意三道门与两条配额**只约束 5 费**，1–3 费不据此判退（2026-09-25 晚修）
- [ ] 脸按 AGENTS.md「脸模」条逐条对（**2026-09-26 二次修**）：**杏仁眼**（上睑只压虹膜上缘一小段，虹膜读成杏仁）/ 上睑线**细到中等 + 外眼角一个短尖**（**不许外飞成猫眼、不许独立睫毛尖**）/ 上睑褶**细而浅**（**不许画成第二条黑线**）/ 虹膜**一块基色 + 边缘一圈略深 + 一枚小高光（约虹膜 1/10）**（**不许大白眼珠、不许深瞳孔点**）/ 眉细、**大部分被刘海挡住**、与上睑线之间留出皮肤 / 下睑一条细浅线（**不许眼袋状暗块**）/ **刘海压住额头与眼上缘** / **不许腮红** / 肤色明显比衣物浅
- [ ] **脸模基准是用户 `脸部参考.docx`（31 张），不是 `01504`** —— `01504` 现在只当全身构图 / 气质 / 明度的库内锚（它仍是库内最好的一张，但低于参考标准）
- [ ] **肤色明显比衣物浅且更暖**，且**没有被低饱和压灰**（肤色不算「一个高饱和点缀色」）
- [ ] 脸模片段**放在角色描述之后**，并在结尾**复述一次**（不要埋在正中间）
- [ ] 文件名与目录符合第 1 节，能被 `CardDisplay2DNew.GetCardArtSprite()` 命中
- [ ] 新 UI 文案若引入新字，先查 `Assets/_Game/Fonts/GameCharacters.txt`（字体图集是静态烘焙，缺字会渲染成空白）
- [ ] 跑一次编译确认工作区没坏：`dotnet build "Assembly-CSharp.csproj" -nologo -v q -p:WarningLevel=0`（基线 **0 错误 / 18 警告**）

## 7. 常见坑

- **`Hero/{cost}` 是 `baseCost`，不是 `baseTier`**。
- **Special 型召唤的图也允许放 `Hero/{cost}`**（01113 传送阵、01306 阴 就是这么放的），代码会兜底；但两处都有图时以 `Special/` 为准。
- **找不到图不会报错**：静默露出前缀底图。所以「图改了没生效」第一件事是查路径，不是查导入设置。
- **别给字体图集加 mipmap**；也别手改贴图导入设置 —— 有自动守卫 `Assets/_Game/Editor/TextureImportSettingsGuard.cs`，菜单 `Tools/设置/贴图导入设置体检 & 修复` 可重跑。
- **别把 `PrefixArtBG` 当前缀底图以外的东西用**：它是「没有立绘时的兜底层」，按前缀各一套色相，不走主配色。
- 改完美术**不要顺手改别的卡**；用户只让改哪张就只改哪张。
