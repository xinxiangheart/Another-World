## 三、`tcg-card-art-director` → `aw-card-art-director`（改旗，2026-09-26）

**原版的问题**：它是给**另一款游戏**（《域·维度战争》/ Zone War）写的，而且核心指令与 `AGENTS.md` **正面冲突** —— 它写着「不要设默认画风，用户用自己的 Midjourney moodboard 控制」，而我们恰恰是**固定画风基准 + 固定前缀 + qwen-image**。更麻烦的是**它的触发词就是我们的日常用语**（「卡图设计部」「卡图方案」…），会被自动命中。

**改旗做了什么**（保留「总监制工作流 + 提示词卫生脚本」，把方言全部换掉）：

| 换掉 | 换成 |
|---|---|
| `《域·维度战争》` / Zone War / 镜界学园 | **Another World** + 本项目仓库路径 |
| `zone-war-art-bible.md` | **`another-world-art-bible.md`** —— 我们的商业化基准、四条设计轴 6 门槛、取景（半身偏七分）、半背景、前缀配色、费用档位、脸模、前缀数据实况 |
| `midjourney-prompting.md`（20 KB 的 MJ 方言） | **`qwen-prompting.md`** —— `qwen-image-3.0-pro` 的**正向句式**：画风串必须第一段、负向词只用于画面禁令、身份写在前 1/3、明度/颜色计划怎么写、失效模式表 |
| 「用户 moodboard 控制画风」 | 「**画风固定，照抄 `AGENTS.md` 的风格提示词前缀，一字不改**」 |
| `域主 / 域灵 / 共鸣域灵 / 域痕 / 结界域痕` | `召唤物（Hero / ChosenOne / Special）` / `法术（Normal / Evil / Counter）` |
| 「全身为主」的取景偏好 | **人形一律半身偏七分，≥6 头身判退** |
| `--ar / --sref / --oref` 参数体系 | 本线路**没有参数** |
| 校验脚本把 `::` 与 `\bZone War\b` 当污染 | 改成查：**prompt 里出现中文**、**卡牌 ID**、**仓库路径**、**身份否定句**（`Not a young woman` 这类）、`narrow eyes`、第三方卡牌游戏名、空词 |
