## 0. 一页纸

| 项 | 内容 |
|---|---|
| 一句话 | 双人对战 · 局内动态构筑 · 12 格线性战场的策略卡牌游戏 |
| 类型 | 回合制卡牌对战（双人 PVP） |
| 平台 | Windows / Steam |
| 单局时长 | 【待测】 |
| 目标玩家 | 【待填】 |
| 对标 / 参考 | 【待填】 |

**三条卖点**

1. **不用赛前组卡** —— 开局没有卡组，和对手共享一副公共大牌库，边打边搭
2. **对位钉死，算的是「人在哪」** —— 12 格线性战场（每方 6 格：前 / 后排各 3），对位由编号绝对决定（`0↔6` … `5↔11`），对位空着就是空打打脸
3. **一阶段三回合，最后一次性同时结算** —— 先手每阶段轮换，后手在单轮内握有「最后行动者优势」

## 1. 设计支柱

1. **规则绝对自洽** —— 所有交互皆有唯一、明确的底层逻辑可循，不留裁定空间
2. **决策深度优先** —— 把计算负担交给系统，把策略抉择交给玩家
3. **资源动态转换** —— 生命值、能量、手牌、战场单位之间存在高风险高回报的转化路径
4. **心理博弈多层** —— 通过隐藏信息（如反制牌的支付方式）和时机抉择增加博弈维度

> 出处：[规则全集](../Assets/_Game/Introduce/指导文本.md) 序言「核心设计哲学」。

## 2. 核心循环

```
开局：20 点生命 · 起始 3 张手牌（2 张普通牌 + 1 张神选者）
  ↓
己方回合 ── 获得 6 点能量（上限 15）→ 召唤 / 施法 / 花能量抽牌
  ↓
敌方回合 ── 对手同样操作
  ↓
战斗回合 ── 全自动结算：战斗回合开始 → 先手 → 全体同时攻击 → 退场与反击
                          → 存活人数对比 → 玩家最终伤害判定
  ↓
阶段结束，先手交换 → 下一阶段（生命掉到 0 出局，可为负）
```

**为什么是「一阶段三回合」**：【待填 · 设计意图】

### 3.1 能量与生命　← 完整示范

**规则**

- 生命 **20**，是胜负判定依据；**可被扣至负数**；可作「血歌」前缀卡牌的支付资源
- 每回合开始 **+6 能量**，**上限 15**；可留存、**可为负、不自动重置**
- 主动抽牌：**1 能量 / 张**，每回合上限 **5 次**；卡牌效果抽牌不受此限
- 神选者另立独立牌堆：开局每人 **1 张**，全局最多还可通过效果再抽 **5 张**
- `+1 / +2` 的口径：加 1 点**当前生命值（同时加上限）**、加 2 点**当前攻击力**

**为什么**

- 能量不重置 → 「攒一波打爆发」和「每回合透支」两种打法能并存，而不是被强制清空
- 生命可当资源 → 「血歌」和快攻有独立节奏线，不必和能量曲线绑定

**边界**

- 反制牌期限到了却没触发：**照样扣费** —— 能量可为负、生命可扣至死
