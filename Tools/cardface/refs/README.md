## 脚本

| 脚本 | 干什么 |
|---|---|
| `fetch_commercial.py` | 抓 4 家商业卡图到 `cardref/`（公开接口，无需 key） |
| `extract_ref_docx.py` | 解包桌面 `图片参考.docx` 的 32 张 PNG 到 `body_ref/` |
| `face_share.py` | 脸高 / 画幅、脸的纵向位置。**口径有坑**：取「最大肤色连通块」，全身立绘上会把**脸 + 胸 + 手**并成一块 → 明显高估（32 张参考被量成 23.9%，实际脸只占画面宽 4–8%）。**只作筛查，判图以人眼放大为准** |
| `baseline_metrics.py` | 分家指标：主体明度跨度 p10→p90、p50、p90、饱和、**肤色占比**、焦点、细节密度 |
| `face_scale_compare.py` | **把每张图的脸统一到 110px 高再并排** —— 同一比例下看服装 / 特效 / 细节 / 头发的差距；输出 `face_scale_compare.png` 到 viz 目录 |
| `thumb_legibility.py` | **缩到卡面尺寸后的明暗标准差**（降到 96×128，透明底按 32 灰合成；whole / subject 两栏）—— 量「缩到 90×118 还认不认得出」 |
| `subject_share.py` | 主体占位（salient blob 占比，粗口径，只作横向对照） |
| `baseline_metrics_v1.py` | `baseline_metrics.py` 的前一版，留作对照，**别用** |

跑法：仓库根目录 `python Tools/cardface/refs/<脚本>.py`。
